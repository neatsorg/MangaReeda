# ブックリストのプラグイン

MangaReeda の表紙サムネイルには、フォルダ・履歴・お気に入りのほかに、プラグインが返す本の一覧をタブとして並べられます。
プラグインは外部のプログラムで、言語は問いません。MangaReeda はプラグインを起動し、標準入力と標準出力でやり取りします。

同梱のプラグインとして、BOOKSCAN の本棚を読む `mangareeda-bookscan` があります（[下記](#bookscan)）。

## 置き場所

`~/.config/MangaReeda/plugins/<名前>/plugin.json` に説明を置きます（`XDG_CONFIG_HOME` があればその下）。

```json
{
  "id": "example",
  "name": "Example",
  "command": ["./example.py"],
  "credentials": [
    { "key": "token", "label": "API トークン", "secret": true }
  ]
}
```

| 項目 | 意味 |
|---|---|
| `id` | プラグインの名前。ダウンロード先のフォルダ名や、ログイン情報の保存にも使う |
| `name` | タブに出す名前 |
| `command` | 実行する命令と引数。`./` で始まるものは `plugin.json` のフォルダから探す |
| `credentials` | 設定画面で入力してもらう項目。`secret` が真なら伏せ字にする。省略可 |

## やり取り

MangaReeda は次のどちらかの引数を付けて `command` を起動し、標準入力に1行の JSON を書きます。

```json
{"credentials": {"token": "…"}}
```

ログイン情報は OS のキーリングに保存したものです。キーリングが使えない環境では、起動しているあいだだけメモリに持ちます。
コマンドライン引数ではなく標準入力で渡すのは、ほかのプロセスから見えないようにするためです。

### `list`

本の一覧を返します。標準出力の最後の行に、次の JSON を書いてください。

```json
{"books": [
  {"id": "…", "title": "書名", "file_name": "書名.pdf", "cover_url": "https://…/cover.jpg"}
]}
```

| 項目 | 意味 |
|---|---|
| `id` | プラグインの中での本の名前。`download` のときにそのまま渡す |
| `title` | 表紙の下と、選んだときの説明に出す |
| `file_name` | ダウンロードした本のファイル名。MangaReeda が開ける形式（`.zip` `.cbz` `.rar` `.cbr` `.pdf`）にする |
| `cover_url` | 表紙の画像の URL。省略可。MangaReeda が取りに行き、手元にためる |

一覧は MangaReeda が手元にためておき、次からはそれを使います。取り直すのは、利用者が「更新」を押したとき（F5）だけです。

### `download <id> <保存先>`

本を `<保存先>` のファイルに書きます。途中で止まっても壊れたファイルが残らないよう、別の名前で書いてから名前を変えてください。
進み具合は、標準出力に1行ずつ次の JSON を書くと、表紙の下に出ます（大きさがわからなければ `total` を省く）。

```json
{"progress": 1048576, "total": 52428800}
```

ダウンロードは1冊ずつ順に行います。

### 終わり方

| 終了コード | 意味 |
|---|---|
| 0 | 成功 |
| 2 | ログインできなかった。設定画面でログイン情報を入れるよう促す |
| ほか | 失敗。標準エラーの最後の行を利用者に見せる |

## ダウンロードした本

設定画面の「プラグイン」で指定したフォルダ（既定はホームの `MangaReeda`）の下に、`<id>/<file_name>` として置きます。
ダウンロードしてある本は、選ぶとそのまま開きます。

## BOOKSCAN

`mangareeda-bookscan` は、[BOOKSCAN](https://www.bookscan.co.jp/) の本棚にある本の一覧を返し、PDF をダウンロードします。
`cargo build --release --workspace` でビルドすると `mangareeda` と同じフォルダにでき、そこにあれば自動で使えます。

1. 設定画面の「プラグイン」で、BOOKSCAN のメールアドレスとパスワードを入れて保存する
2. 表紙サムネイルの「BOOKSCAN」タブを開くと、本棚の一覧を取りに行く
3. 本を選ぶと PDF をダウンロードし、終わったら開く

BOOKSCAN の利用規約に従って使ってください。サイトに負担をかけないよう、本棚のページは間を空けて取り、ダウンロードは1冊ずつ行います。一覧の更新も、利用者が頼んだときだけです。
サイトの作りが変わると動かなくなることがあります。

参考にしたもの: [snaka/download-bookscan](https://github.com/snaka/download-bookscan)（MIT License）。コードは含みません。
